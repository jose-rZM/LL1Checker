Generate a formatted snippet around an error location. 

Given an {\ttfamily input} string and a byte-\/offset {\ttfamily pos}, extracts a few lines of context and places a caret (\texorpdfstring{$^\wedge$}{\string^}) under the error column. Also computes the zero-\/based line ({\ttfamily out\+\_\+err\+\_\+line}) and column ({\ttfamily out\+\_\+err\+\_\+col}).
